Bubble Craps — Deployment Guide
================================

Connect to the Pi
-----------------
  ssh lucky@craps.local


First-time setup
----------------
1. Clone the repo (if not already there):
     cd ~
     git clone https://github.com/joshuaberg/bubble-craps.git

2. Create a virtual environment:
     cd ~/bubble-craps/machines/craps
     python3 -m venv venv

3. Install dependencies:
     source venv/bin/activate
     pip install -e ".[pi]"

4. Bring up the CAN bus (needed after every reboot, or add to /etc/network/interfaces):
     sudo ip link set can0 up type can bitrate 1000000

5. Install the systemd service:
     sudo cp machines/craps/deploy/bubble-craps.service /etc/systemd/system/
     sudo systemctl daemon-reload
     sudo systemctl enable bubble-craps

6. Start it:
     sudo systemctl start bubble-craps


Updating code
-------------
On your Mac: commit and push to main.

On the Pi:
  cd ~/bubble-craps
  git pull origin main
  sudo systemctl restart bubble-craps


Common commands
---------------
Start:      sudo systemctl start bubble-craps
Stop:       sudo systemctl stop bubble-craps
Restart:    sudo systemctl restart bubble-craps
Status:     sudo systemctl status bubble-craps
Live logs:  journalctl -u bubble-craps -f
All logs:   journalctl -u bubble-craps


Manual testing (service must be stopped first)
----------------------------------------------
  sudo systemctl stop bubble-craps
  cd ~/bubble-craps/machines/craps
  source venv/bin/activate
  sudo venv/bin/python scripts/demo.py --count 3 --save-images
  sudo venv/bin/python scripts/calibrate.py


Monitoring MQTT (from any machine on the network)
-------------------------------------------------
Subscribe to all topics:
  mosquitto_sub -h <broker-ip> -t "bubble-craps/#" -v

Send a roll command:
  mosquitto_pub -h <broker-ip> -t "bubble-craps/bubble-craps-01/command" -m '{"action": "roll"}'

Change to remote mode:
  mosquitto_pub -h <broker-ip> -t "bubble-craps/bubble-craps-01/command" -m '{"action": "set_mode", "mode": "remote"}'

Change to timer mode (interval in seconds, minimum 60):
  mosquitto_pub -h <broker-ip> -t "bubble-craps/bubble-craps-01/command" -m '{"action": "set_mode", "mode": "timer", "interval_sec": 120}'

Clear error state:
  mosquitto_pub -h <broker-ip> -t "bubble-craps/bubble-craps-01/command" -m '{"action": "clear_error"}'

Request status:
  mosquitto_pub -h <broker-ip> -t "bubble-craps/bubble-craps-01/command" -m '{"action": "status"}'


Disabling the service (stop auto-start on boot)
------------------------------------------------
  sudo systemctl disable bubble-craps
  sudo systemctl stop bubble-craps


CAN bus note
------------
The CAN interface must be up before the service starts. If it's not
configured to come up automatically, you'll see CAN errors in the logs.

To bring it up manually:
  sudo ip link set can0 up type can bitrate 1000000

To make it persistent, add to /etc/network/interfaces:
  auto can0
  iface can0 can static
    bitrate 1000000
